# Projeto de auditoria pública de sites

Projeto estático em português para revisar publicamente:

- https://conectproo.com/
- https://dracounlocker.com/
- https://kenncellserver.com/

## Arquivos

- `index.html`: painel estático com resumo, achados e próximos passos.
- `AUDITORIA.md`: relatório detalhado da coleta, limitações, evidências e recomendações.

## Publicação

O projeto está no repositório privado `Mavincwb2022/auditoria-sites-gsm`. A página `index.html` pode ser hospedada pelo GitHub Pages se a publicação pública for desejada.

## Escopo

Revisão passiva de páginas públicas. Não inclui varredura, exploração, login, compra ou envio de dados pessoais. Os resultados são observações da superfície pública, não um laudo jurídico ou pentest.
